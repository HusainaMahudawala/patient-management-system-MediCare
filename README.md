# MediCare+ 🏥

MediCare+ is a modern MERN Stack Patient Management System designed to simplify healthcare management through a secure and responsive patient portal.

The application provides authentication, appointment booking, medical reports management, profile handling, and a dynamic healthcare dashboard with real-time backend integration.

---

# 🚀 Features

## 🔐 Authentication System
- User Registration
- User Login
- JWT Authentication
- Protected Routes
- Logout Functionality
- Password Hashing using bcrypt

---

## 📊 Dashboard
- Modern Healthcare Dashboard UI
- Responsive Sidebar Navigation
- Dynamic Dashboard Cards
- Appointment Statistics
- Notifications Panel
- Upcoming Schedule
- Patient Overview Section

---

## 📅 Appointment Management
- Book Appointments
- View Appointment History
- Edit Appointments
- Delete/Cancel Appointments
- Appointment Status Tracking
- Dynamic Appointment Data from MongoDB

---

## 👤 Patient Profile
- View Profile
- Edit Personal Information
- Dynamic User Data
- Profile Management System

---

## 📁 Medical Reports
- Upload Reports/Documents
- View Reports
- Download Reports
- Delete Reports
- Report Management System

---
